MidiAI Installer.exe

공식 설치 · 업데이트 프로그램

MidiAI Installer는 MidiAI Studio의 설치·업데이트·복구를 한 마법사에서 처리하는 Windows 전용 도구입니다. 설치 준비에서 작업을 선택한 뒤 다음으로 진행합니다.

  • Installer
  • Updater
  • Runtime Manager

Setup

설치 방법

  1. 위 다운로드 버튼으로 MidiAI Installer.exe를 받습니다.
  2. 설치 파일을 실행하고 설치 경로를 확인합니다. 기본 경로는 C:\MidiAI입니다.
  3. 설치 준비에서 설치/업데이트를 선택한 뒤 다음을 누릅니다. 미설치면 전체 설치, 이미 설치된 경우 최신 파일로 구성됩니다.
  4. 마법사가 시작 → 설치 준비 → 설치 → 완료 순서로 진행됩니다. 설치 위치는 C:\MidiAI로 고정되어 있습니다.
  5. 완료 화면이 나오면 마법사를 닫고 C:\MidiAI에서 MidiAI Studio를 실행할 수 있습니다.

Run

실행 · 업데이트 방법

  1. 이미 설치된 경우 Installer를 다시 실행한 뒤 설치 준비에서 설치/업데이트를 선택하고 다음으로 앱을 갱신합니다.
  2. 실행 오류나 파일 누락이 있으면 같은 화면에서 복구를 선택한 뒤 다음으로 복구를 진행합니다.
  3. 설치 후 C:\MidiAI 폴더에서 MidiAI Studio를 실행합니다.
  4. 라이선스 인증은 앱 실행 후 Google 계정으로 로그인해 진행합니다.
  5. 문제가 계속되면 오류 메시지, 스크린샷, 로그 파일(가능한 경우)을 첨부해 1:1 문의를 이용해 주세요.
