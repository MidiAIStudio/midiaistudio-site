MIDI 편집·피아노롤 사용법 (MidiAI Studio)

변환 결과를 피아노롤에서 다듬습니다. 트랙별 악기 변경, 노트 길이·벨로시티, 양자화를 지원합니다.

단계별 안내

  1. MIDI 열기

    변환 결과 또는 라이브러리 MIDI를 엽니다.

  2. 노트 편집

    피치·길이·벨로시티를 조정하고 악기를 바꿉니다.

  3. 저장·내보내기

    저장하거나 악보(PDF·MusicXML)로 내보냅니다.

화면 스크린샷과 최신 단계는 아래에서 불러옵니다. Firestore를 읽지 못하는 환경에서도 위 요약은 HTML에 포함됩니다.
