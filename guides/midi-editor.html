MIDI 편집과 피아노롤 사용법

MIDI 에디터는 변환 결과를 연주 가능한 데이터로 다듬는 단계입니다. 음원·유튜브·PDF 변환 후 거의 항상 이 화면으로 이어집니다.

어떤 상황에서 쓰나요

AI가 만든 MIDI는 초안입니다. 겹친 음, 옥타브 실수, 리듬이 어긋난 구간은 피아노롤에서 직접 고칩니다. 멜로디와 반주를 트랙으로 나눠 악기를 바꾼 뒤, 라이브러리에 저장하거나 PDF·MusicXML 악보로 내보낼 수 있습니다.

에디터에서 다루는 것

  • 멀티트랙 피아노롤에서 노트 피치·길이 수정
  • 벨로시티로 셈여림 조절
  • 트랙별 악기 변경
  • 양자화로 그리드에 맞추기
  • 편집 후 MIDI → PDF / MusicXML 저장

권장 순서

  1. 변환된 MIDI를 에디터에서 엽니다.
  2. 멜로디와 반주 트랙을 나눕니다.
  3. 겹친 음·옥타브 오류를 고칩니다.
  4. 저장하거나 악보로 내보냅니다.

버튼 위치와 화면 단계는 MIDI Editor 사용 가이드를 보세요. 입력은 음원 MIDI, 유튜브 MIDI, 악보 PDF MIDI와 이어집니다.

FAQ

MIDI 편집 프로그램에서 무엇을 고치나요?

피치, 길이, 벨로시티, 트랙 악기, 양자화 등 변환 직후 남는 오류를 피아노롤에서 수정합니다.

실행취소가 되나요?

네. 일반적인 편집 작업에 실행취소/다시실행을 지원합니다.
